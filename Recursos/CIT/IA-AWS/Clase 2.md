## Amazon SageMaker

### Ground Truth

 Se le pasa los datos para poder entrenarla de una mejor manera y para datos de tipo etiquetado humano.
Se puede usar para normalizar los datos que nosotros tenemos.

### Notebook

Tienen modelos para nosotros podemos usarlas en nuestras aplicaciones en producción

### Training

- Podemos pasar un modelo que tengamos o un modelo del Notebook para poder entrenarla de una mejor manera

### Inference

Crea modelos para trabajos de de entrenamiento,

Las skills están de manera bloqueada

### AWS Marketplace

Se pueden encontrar modelos ya creados en donde tenemos una variedad de opciones

>[!note]
>Amazon nos puede entregar una instancia con una grafica de video para poder facilitar el entrenamiento siempre y cuando se ponga capital

>[!info]
**Inferencia elastica:**  Es un servidor de inferencia en donde se toman datos de diferentes servidores de inferencia para poder mejorar nuestros

>[!note]
**IAM role:** Depende del rol del IAM es que tantos accesos y roles se van a  trabajar.

>[!success]
>Monitorieo de manera centralizada en torno al proyecto es Cloud watch
