#  2.1.4 Práctica - Normativas

Al planificar y determinar el alcance de una prueba de penetración, a menudo hay muchas consideraciones de cumplimiento normativo. Aunque algunas de estas regulaciones no se aplican a Pixel Paradise, es importante que las conozca a medida que ampliamos la interacción con los clientes. Haga coincidir la descripción o el requisito de cumplimiento con el marco regulatorio relevante.

![[Pasted image 20260613150701.png]]



|**Categoría**|**Opción Correcta (Descripción)**|
|---|---|
|**A. NIST SP 800-57**|**directrices para la administración de claves de cifrado** _(Es el estándar técnico que define cómo gestionar, almacenar y proteger las claves criptográficas)_.|
|**B. GDPR**|**refuerza y unifica las protecciones de privacidad de datos para las personas dentro de la Unión Europea** _(Es el reglamento integral de protección de datos personales en la UE)_.|
|**C. Ley GLBA**|**se aplica a todas las organizaciones de servicios financieros, independientemente del tamaño** _(Exige que las instituciones financieras expliquen sus prácticas de intercambio de información y protejan datos sensibles)_.|
|**D. HIPAA**|**protege la información médica electrónica** _(Regulación clave para el sector salud sobre la privacidad y seguridad de datos de pacientes)_.|
|**E. PCI DSS**|**asegura el procesamiento de tarjetas de crédito y otros tipos de pagos digitales** _(Estándar de seguridad obligatorio para empresas que manejan tarjetas de pago)_.|
