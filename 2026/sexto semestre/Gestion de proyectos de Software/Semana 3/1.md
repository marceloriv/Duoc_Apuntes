## Cronograma y EDT

**Diferencia entre EDT y Cronograma:**

| | EDT | Cronograma |
| --- | --- | --- |
| **Qué responde** | ¿Qué se va a construir? | ¿Cuándo se va a hacer? |
| **Contenido** | Entregables descompuestos en jerarquía (niveles, paquetes de trabajo) | Actividades ordenadas en el tiempo con duraciones y responsables |
| **Herramienta** | Diagrama tipo árbol (WBS) | Carta Gantt o diagrama de red |
| **Se vincula a** | Alcance del proyecto | Tiempo y recursos del proyecto |
| **Fase asociada** | Planificación / Ejecución | Ejecución / Monitoreo y Control |

> [!tip]
> La EDT define **qué** se construye; el cronograma define **cuándo** se ejecuta. Primero se arma la EDT y luego se integra al cronograma asignando tiempos y responsables a cada entregable.

El diagrama de EDT va amarrado a la fase de **Ejecución**.

### Convenciones para el cronograma

- En la plantilla del cronograma del proyecto solo se consideran los **días hábiles**.
- Al asignar una tarea, colocar solo las **3 iniciales** (Nombre + 2 apellidos).
  - Si en la misma tarea van 2 personas, se separan por coma: `EPF, CBP`.
- En el diagrama EDT se debe tener una rotulación con **versionado numérico**.

### Convenciones de colores (Carta Gantt)

| Color | Significado |
| --- | --- |
| Verde oscuro | Tiempo programado (dentro de lo planificado) |
| Verde claro | Tiempo programado que se pasó de la fecha original |
| Amarillo | Tiempo que se excedió de lo programado |
