# 21 - 08 - 2026

## Librerías de autenticación e integración

- **MSAL (Microsoft Authentication Library)**:
  - Biblioteca estándar para autenticación mediante OAuth 2.0 y OpenID Connect (OIDC).
  - Permite a la aplicación adquirir tokens para autenticar usuarios de cuentas Microsoft y Azure AD (Microsoft Entra ID).
- **Microsoft Graph**:
  - API REST unificada que permite acceder a los datos y servicios de Microsoft Cloud (usuarios, grupos, perfiles, archivos y calendarios).

## Bases de datos en arquitecturas Cloud Native

En entornos cloud con servicios administrados dentro de la misma VPC o región, la latencia entre bases relacionales y no relacionales suele ser comparable a nivel de red.

### Relacional (SQL) vs. No Relacional (NoSQL)

- **Bases relacionales (SQL)**:
  - La integridad referencial está garantizada a nivel del motor mediante restricciones de clave primaria (`PK`) y clave foránea (`FK`).
  - El motor rechaza inconsistencias de forma nativa (modelo ACID).
- **Bases no relacionales (NoSQL)**:
  - No cuentan con claves foráneas nativas para forzar relaciones entre colecciones o documentos.
  - **Responsabilidad del backend**: la lógica de la aplicación debe ser lo suficientemente consistente y robusta para evitar registros huérfanos, coordinar escrituras distribuidas y mantener íntegras las relaciones entre entidades de negocio.
