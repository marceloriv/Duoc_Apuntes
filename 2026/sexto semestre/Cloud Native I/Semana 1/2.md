## Versión de API

El versionado de API se justifica por cambios en:

- Nivel de seguridad
- Tipos de solicitud
- Políticas
- Headers de las solicitudes

> [!NOTE]
>Se recomienda que el versionado de la API se haga a través de la URL, ya que es más fácil de documentar y entender.
---
> [!CAUTION]
>Se recomienda versionar la API cuando cambie la compatibilidad.

## CORS

- Cuando se usa una **API pública** se permite todo, es decir `*`, ya que cualquiera la puede usar.
- Cuando es una **API propia** se especifica la URL del consumidor que se debe usar, por temas de seguridad.
